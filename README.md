# Stairs

**一個「要照順序做」的待辦清單網頁。**

做完第 1 階，才能做第 2 階；前面沒完成，後面就鎖住 🔒。
全部做完會跳出慶祝畫面 🎉。

```
✓ 找題目
✓ 讀文獻
☐ 寫大綱      ← 目前這一階（只有它能打勾）
🔒 寫初稿     ← 鎖住
🔒 修改       ← 鎖住
```

## 功能

| 編號 | 功能 |
|---|---|
| F1 | 多個專案，可新增、切換 |
| F2 | 新增步驟；按住步驟拖曳換順序（手機長按約 0.4 秒），鍵盤用 Alt+↑ / Alt+↓（只能在未完成的步驟之間換） |
| F3 | 後面的步驟鎖住、變灰 |
| F4 | 打勾目前這一階 → 下一階自動解鎖 |
| F5 | 全部完成時跳出慶祝畫面 |
| F6 | 取消打勾 → 這一階和後面的全部一起退回 |
| F7 | 專案和步驟都能改名、刪除 |
| F8 | 專案截止日期（建立時設定或跳過；月曆＋24 小時制整點滾輪） |
| F9 | 未完成專案照截止日期排序，每天一條灰色分隔線 |
| F10 | 畫面最下面切換「未完成／已完成」；已完成專案變灰並標出完成日期 |
| F11 | 「加入行事曆」：下載 `.ics` 檔，由手機／電腦的行事曆在截止前 24 小時提醒（之後改截止日期要重新加入） |

**核心規則：** 已完成的步驟一定是「從第 1 階開始、連續的一段」。`✓ ✓ □ □` 可以，`✓ □ ✓ □` 不行。

## 特色

- **雙擊 `index.html` 就能用。** 不用伺服器、不用安裝、可以離線。（線上版打開時要有網路。）
- 純 HTML / CSS / JavaScript，沒有框架、沒有 npm、沒有外部套件。
- 資料存在瀏覽器的 `localStorage`（key：`stairs.v1`），重新整理不會不見。
- 支援手機、深色模式、只用鍵盤操作。
- 介面是繁體中文。

**不做的事（v1）：** 帳號、雲端同步、分享、Stairs 自己的推播通知（提醒交給行事曆，見 F11）、子步驟、匯出入（行事曆檔除外）、復原（Undo）。

## 怎麼用

| 想做什麼 | 怎麼做 |
|---|---|
| 電腦上使用 | 雙擊 `index.html` |
| 手機上使用 | 打開 <https://yoshi8615.github.io/stairs/>，再用瀏覽器的「加入主畫面」 |
| 跑自動測試 | 雙擊 `test.html`，最上面顯示「通過 Y / Y」就是全過 |

### 資料存在哪

- 資料只存在**你打開它的那個瀏覽器**裡，不會上傳。換電腦、換瀏覽器，看到的都是另一份。
- iPhone：主畫面 App 和 Safari 分頁的資料**也是分開的**，請固定用主畫面圖示打開。刪掉主畫面圖示，資料會一起刪掉。只在 Safari 分頁裡用的話，7 天沒打開，資料可能被系統清掉。
- **沒有備份**（匯出入不在 v1 範圍內），重要的東西請另外記一份。
