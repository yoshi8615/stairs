# Stairs

**一個「要照順序做」的待辦清單網頁。**

做完第 1 階，才能做第 2 階；前面沒完成，後面就鎖住 🔒。
全部做完會跳出慶祝畫面 🎉。

```
✓ 找題目
✓ 讀文獻
☐ 寫大綱      ← 目前這一階（只有它能打勾）
🔒 寫初稿     ← 鎖住
🔒 修改       ← 鎖住
```

## 功能

| 編號 | 功能 |
|---|---|
| F1 | 多個專案，可新增、切換 |
| F2 | 新增步驟；拖曳或 ↑↓ 按鈕換順序（只能在未完成的步驟之間換） |
| F3 | 後面的步驟鎖住、變灰 |
| F4 | 打勾目前這一階 → 下一階自動解鎖 |
| F5 | 全部完成時跳出慶祝畫面 |
| F6 | 取消打勾 → 這一階和後面的全部一起退回 |
| F7 | 專案和步驟都能改名、刪除 |

**核心規則：** 已完成的步驟一定是「從第 1 階開始、連續的一段」。`✓ ✓ □ □` 可以，`✓ □ ✓ □` 不行。

---

## 特色

- **雙擊 `index.html` 就能用。** 不用伺服器、不用安裝、可以離線。
- 純 HTML / CSS / JavaScript，沒有框架、沒有 npm、沒有外部套件。
- 資料存在瀏覽器的 `localStorage`（key：`stairs.v1`），重新整理不會不見。
- 支援手機、深色模式、只用鍵盤操作。
- 介面是繁體中文。

**不做的事（v1）：** 帳號、雲端同步、分享、截止日期、子步驟、匯出入、復原（Undo）。
